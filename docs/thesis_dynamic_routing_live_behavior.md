### พฤติกรรมจริงของ Dynamic Routing และ Circuit Breaker (การใช้งานจริง)

ตรวจสอบพฤติกรรมจริงของกลไกจัดเส้นทางโมเดล (proposal 4.1.6) จาก `prediction_log` ตั้งแต่ deploy โมเดล v3
(19 ก.ย. 2569 เป็นต้นไป, 11,856 แถว)

| โมเดลที่ระบบเลือกใช้จริง | สัดส่วน |
|---|---|
| LightGBM | 51.6% |
| XGBoost | 47.8% |
| naive_fallback (circuit breaker) | 0.6% |

ระบบเลือกใช้ทั้งสองโมเดลในสัดส่วนใกล้เคียงกันอย่างสม่ำเสมอทุกช่วงเวลาพยากรณ์ (45-54% ทั้งคู่ในทุก
horizon bucket) สอดคล้องกับผลเปรียบเทียบประสิทธิภาพที่พบว่าทั้งสองโมเดลมีความแม่นยำใกล้เคียงกันมาก
ยืนยันว่ากลไก Dynamic Routing ทำงานตามที่ออกแบบไว้จริงในระบบใช้งานจริง ไม่ใช่แค่ทฤษฎี

กลไกสำรอง (Circuit Breaker) ทำงานน้อยมาก (0.6%, 72 ครั้ง) และเกิดขึ้นเฉพาะจังหวัดเดียว (นครพนม)
ในช่วงเวลาสั้นๆ 2 ชั่วโมง สะท้อนว่าข้อมูลนำเข้าขาดหายเป็นเหตุการณ์ที่พบได้น้อยและมักจำกัดวงแคบ ไม่ใช่
ปัญหาที่เกิดกระจายทั่วทั้งระบบ

**ไฟล์ต้นทาง**: query ตรงจาก `prediction_log` ผ่าน `scripts/analyze_dynamic_routing_live_behavior.py`
